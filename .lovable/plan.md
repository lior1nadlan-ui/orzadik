
## סקירה
אני אהפוך את האתר לפרקטי יותר בסגנון rikmat.com, תוך שמירה מלאה על העיצוב והתמונות הקיימים.

## 1. מבצע 30% + העלאת מחירים 20%
- **מחירים בבסיס נתונים**: אעלה את כל מחירי `products.price` ב-20% (UPDATE) ואשמור את המחיר המקורי ב-`sale_price` כדי שיוצג מחיר מחוק.
  - דרך טכנית: `UPDATE products SET sale_price = price, price = ROUND(price * 1.2)` ואז המחיר האפקטיבי שמוצג ללקוח = price * 0.7 (אחרי הנחת 30%).
- **חישוב צד-שרת**: ב-`checkout.functions.ts` המחיר האפקטיבי = `price * 0.7`. גם בקופה.
- **פס זהב עליון**: באנר זהב עם הטקסט "מבצע מיוחד | 30% הנחה על כל האתר 🎁" - יתווסף ב-__root.tsx מעל ה-Header.
- **תצוגת מחירים**: ProductCard, ProductPage, Cart, Checkout - יציגו מחיר מקורי מחוק + מחיר אחרי הנחה בזהב, ותג "30%-".

## 2. עמוד מוצר משופר (כמו rikmat)
שדרוג `product.$slug.tsx`:
- כותרת + תמונה ראשית (קיים)
- תג זמינות "במלאי" / "אזל"
- כמות + **"הוסף לעגלה"** + **"קנה עכשיו"** (חדש - מוסיף ונווט לקופה)
- **שדה רקמה אישית** - אם המוצר בקטגוריה טלית/תפילין/כיסוי: input "שם לרקמה (אופציונלי)" - יישמר ב-cart item ויעבור להזמנה (notes).
- אקורדיון: תיאור מוצר / משלוחים / מדיניות החזרות והחלפות
- "לקוחות שרכשו מוצר זה התעניינו גם ב..." - גריד 4 מוצרים מאותה קטגוריה.

## 3. עמוד קטגוריה משופר
שדרוג `category.$slug.tsx`:
- כותרת קטגוריה גדולה + תמונת באנר (משדה חדש `categories.image_url`)
- תיאור הקטגוריה (קיים) + טקסט הרחבה
- שורת סינון/מיון: זמינות (במלאי/הכל), מחיר מעד, מיון (מומלצים / מחיר נמוך-גבוה / גבוה-נמוך / חדש לישן / ישן לחדש)
- ספירת מוצרים
- בלוק תוכן SEO תחתון על הקטגוריה

## 4. שינויי סכימה (Migration)
- הוספת `image_url` ו-`long_description` ל-`categories`
- הוספת `custom_text` (TEXT, nullable) ל-`order_items` עבור רקמה אישית
- עדכון מחירים: `UPDATE products SET sale_price = price, price = ROUND(price * 1.2 * 100) / 100`
