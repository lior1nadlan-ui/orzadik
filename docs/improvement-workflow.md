# תהליך עבודה — סבבי שיפור ושדרוג

המסמך הזה מגדיר איך מתבצע כל סבב שיפור באתר, ומחזיק את ה-backlog המתועדף.
הוא נכתב כדי שכל סוכן או מפתח שממשיך את העבודה יתחיל מאותה נקודה, ולא ינחש.
מקור אמת לכללי העבודה: `CLAUDE.md`. זיכרון מתמשך: טבלת `agent_memory` בפרויקט orzadik.

## המחזור — כל סבב

1. **מדידה.** נתונים חיים מפרויקט Supabase `whtjslgrrfzehivrknuv` בלבד:
   הזמנות ומשפך, עגלות, בריאות הקטלוג (תמונה, מחיר, קטגוריה, תיאור),
   קטגוריות גדולות בלי מדריך, advisors של אבטחה וביצועים, מצב CI והפריסה האחרונה.
2. **בחירה.** פריט אחד או שניים מה-backlog למטה — לפי השפעה מדידה, לא לפי נוחות.
   מה שדורש החלטת בעלים (כסף, משפט, הגדרות בדשבורד) לא מבוצע — נרשם ב"ממתין לבעלים".
3. **בנייה.** שינוי מינימלי וממוקד.
   - לוגיקה: מודול טהור עם בדיקות Vitest.
   - תוכן: מבוסס על נתוני הקטלוג החיים; בלי מחירים בטקסט; מקורות הלכתיים מצוטטים כלשונם;
     היכן שהמנהג משתנה — מתארים ומפנים לרב.
   - מיגרציה: קובץ ב-`supabase/migrations` + החלה על `whtjslgrrfzehivrknuv`, ובדיקה שהשורה
     השמורה זהה לקובץ (md5).
4. **אימות.** `npm run lint`, `npm run typecheck`, `npm run test`, `npm run build`,
   ובדיקה חזותית בתצוגה מקומית (mock) בגודל מובייל.
5. **שילוב.** PR → CI ירוק → מיזוג → בדיקה ש-`deploy.yml` הסתיים בהצלחה.
   האתר החי מתעדכן רק מהפריסה ל-Cloudflare; preview של Vercel אינו האתר.
6. **תיעוד.** upsert ל-`agent_memory` (לפי `key`) ועדכון ה-backlog כאן.
7. **דיווח.** מה נעשה, מה נבדק ואיך, ומה ממתין לבעלים.

### ממצאי הלמידה — ניהול מוצרים (2026-09-26)

איך זה עובד היום (`src/routes/admin.products.tsx`, `src/lib/admin-products.functions.ts`):

- **רשימת המוצרים:** חיפוש לפי שם, מק"ט או כתובת, סינון "בלי תמונה" / "אזל", 25 בעמוד. **אין סינון לפי קטגוריה.**

- **מה הלקוח משלם:** האתר מוריד 30% מהמחיר שנשמר (`SITE_DISCOUNT`), ועוד 5% לחברי מועדון. הטופס מציג רק את המחיר השמור, בלי המחיר שהלקוח משלם.
- **"מחיר מבצע":** השדה `sale_price` הוא בפועל המחיר **הקודם** שמוצג מחוק ליד המחיר. השם בטופס מטעה. 171 מוצרים פעילים משתמשים בו.
- **באג:** 216 מוצרים פעילים נשמרו בעבר עם כתובת בעברית, והטופס דורש כתובת באנגלית בכל שמירה — כך שאי אפשר לשנות להם מחיר בלי לשנות גם את הכתובת שלהם.
- **הוספת מוצר:** תמונה אחת עד 5MB, בלי הקטנה או המרה ל-WebP. תמונות הגלריה (3,780 תמונות ל-2,592 מוצרים) לא ניתנות לעריכה מהממשק. 102 קטגוריות ברשימת תיבות סימון לפי א-ב, בלי היררכיה ובלי חיפוש. לשם עברי צריך להקליד כתובת באנגלית ידנית.
- **בפועל:** אף מוצר לא נושא תמונה שהועלתה דרך הממשק (0 ב-`uploads/`), והמוצר האחרון נוסף ידנית ב-22.7.2026.

  לשייך אותם מחדש באדמין (ואם אין תיקי PVC, להסתיר את הקטגוריה). שני קליפסים לטלית, ששויכו לקטגוריות
  של רקמה, הוחרגו בקוד מהצעת השם האישי.
- **טליתות "פאר" — מה החומר?** 7 דגמים באותה סדרה ובאותו מחיר מתוארים פעם כ"משי", פעם כ"100% צמר רחלים"
  ופעם כ"100% צמר מרינו". ייתכן שכל דגם שונה — צריך לבדוק מול הסחורה. צמר מול סינתטי חשוב גם לציצית. את הטענה
  "עשויה מכסף טהור 925" (בטלית!) כבר הסרתי; כדאי לאשר את החומר של כל דגם ולתקן בעמוד המוצר.
- **קופות צדקה — תיאור קצר שסותר את השם:** "קופת צדקה פח מרובעת 'עיטורים'" ו"'שיש זהב'" מתוארות
  כ"חומר: פרספקס"; "קופת צדקה אקריליק עם הדפסה - נצנצים כסף 13 ס"מ" מתוארת כ"חומר: קריסטל" ובאורך 11 ס"מ.
