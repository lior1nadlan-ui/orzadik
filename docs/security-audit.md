## 3. סיכונים פתוחים — פעולות שלך (לא באגי קוד)

**קריטי:**
1. **להחיל את המיגרציות על ה-DB החי** — תיקון הסלמת `is_member` ו-RLS של הביקורות **לא פעילים** עד ההרצה.
2. **MFA לאדמין + Leaked Password Protection** ב-Supabase Auth — בלי MFA, פריצת חשבון אדמין = גישה לכל הנתונים.
3. **`CARDCOM_ALLOWED_IPS`** — כרגע fail-open; להגדיר כדי לאכוף מקור webhook.

**מומלץ:**
4. `npm audit fix` (עם בדיקת build).
5. להריץ **Supabase Security Advisor** על הפרויקט החי (בודק RLS/Auth שאי אפשר לבדוק מהקוד).
6. להוסיף `.env` ל-`.gitignore` (מכיל רק מפתחות ציבוריים, אך כהגנת עומק).
7. סודות להגדרה: `UNSUBSCRIBE_SECRET`, `RESEND_API_KEY`, `CRON_SECRET`, `SUPABASE_SERVICE_ROLE_KEY`.
