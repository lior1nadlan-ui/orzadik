# תיק ציות — פרטיות ואבטחת מידע · "אור זרוע לצדיק"

**כל המסמכים הם טיוטות עבודה שהוכנו בעזרת AI ומבוססות על מבנה המערכת בפועל — אינם תחליף לייעוץ עו"ד מורשה, ויש להעבירם לבדיקה משפטית לפני אימוץ.**

## מה כבר מיושם בקוד (אבטחה ופרטיות)
TLS/HTTPS · סודות ב-Vault · RLS על כל הטבלאות הרגישות · `has_role` לאדמין · זהות מ-JWT · בידוד אסימוני תשלום (server-only) · אימות webhook שרת-לשרת + idempotency · ולידציית Zod · DOMPurify · גיבוי יומי · זכות עיון (ייצוא עברי) · תיקון (עריכת פרופיל) · מחיקה/אנונימיזציה · **יידוע §11 מורחב (תיקון 13)** בצ'קאאוט/הרשמה/שיווק כולל מקבלי מידע (Supabase/Cardcom/Resend) וזכויות §13/§14 · הסכמת שיווק Opt-In (כבויה כברירת מחדל) · **תאימות חוק הספאם** (סימון "פרסומת", זיהוי מפרסם, קישור הסרה חתום ומנגנון הסרה) · **חוק הגנת הצרכן**: גילוי עוסק §4ב, גילוי טרם עסקה §14ג(א), אישור בכתב במייל §14ג(ב), ביטול 14 יום + דמי ביטול §14ג-ה, מחיר כולל מע"מ §17א · **מחיר מבצע הוגן** (מחיר מחוק רק לפי מחיר קודם אמיתי, §2) · באנר עוגיות גרנולרי · TTL לעגלות נטושות.

> יישום מלא ומיפוי לכל 6 החוקים: ראו [`../legal-compliance-implementation.md`](../legal-compliance-implementation.md).

## פעולות פתוחות — בעלים / עו"ד (לא ניתנות ליישום בקוד)
**מיידי (P0)**
- [ ] לפתוח/לאמת תיבות דוא"ל תחת הדומיין האמיתי (privacy@ / accessibility@) ולאשר: `orzarua.co` או `orzarua.co.il`?
- [ ] למסור זהות משפטית מלאה: שם עוסק/ח.פ, מס' עוסק, כתובת, טלפון (לתקנון ולמדיניות).
- [ ] להפעיל ב-Supabase Auth: **MFA לאדמין** + **Leaked Password Protection** + מדיניות סיסמה.

**גבוה (P1)**
- [ ] לחתום **DPA** מול Cardcom, Lovable, Supabase, **Resend (מייל — כבר פעיל)** (ובעתיד חברת משלוחים).
- [ ] למלא ב-`src/lib/business.ts` את `legalId` (עוסק/ח.פ) ו-`address`, ולהגדיר `UNSUBSCRIBE_SECRET`.
- [ ] לאשר משפטית את נוסחי מדיניות הפרטיות/ההסכמה שעודכנו.
- [ ] לאמץ רשמית את מסמכי 01–02 לאחר השלמת השדות ובדיקת עו"ד.

**בינוני (P2)**
- [ ] להחתים עובדים/קבלנים על התחייבות סודיות (סעיף 16).
- [ ] להגדיר שמירת לוגי גישה (24 ח') ובדיקת שחזור רבעונית מתועדת.
- [ ] לבדוק: האם נאסף מידע "רגיש" בשדות חופשיים? האם יש לקוחות מה-EEA? היקף נושאי המידע (סף 100k / סיווג עסק)?

**הערה על אסמכתאות:** הנוסח שנמסר (`9_lsr_208332.pdf`) הוא נוסח 1981 המקורי. לעיגון מדויק של הוראות תיקון 13 (ביטול רישום, פטור DPO, פיצוי ללא נזק, התיישנות 7 שנים, עיצומים) יש להסתמך על הנוסח המשולב המעודכן.
